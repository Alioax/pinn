# M-series (PINO_3, mixed piecewise+GRF training) - paper heterogeneous section.
# Prior batches DONE: X3/X4/X6 SOAP replicates + G01-G12 GRF grid (result dirs exist).
#
# Motivation: X3 (pure 5-zone piecewise) = 2.04% in-distribution but fails
#             cross-zonation OOD (223%); G01 (pure GRF) = 4.70% but stays stable OOD.
#             The mix axis tests whether one training set gets both.
# Grid  : GRF share in {0, 25, 50, 75, 100}% of N=500 (M0-M4)
#         + one K=50 control at the 50/50 mix (M5) to re-test the
#         "more sensors hurt at short ell" finding under mixed training.
# Fixed : N=500 total, K=101 sensors (aligned with the COMSOL 0.01 grid;
#         a 5%-min zone gets ~5 sensors), GRF ell=0.05, piecewise 5-zone ONLY
#         with min-zone-frac 0.05 (X3 used 0.10 -> M0 re-anchors the 0% endpoint
#         under the new protocol; M4 re-anchors 100% vs G02's K=100),
#         float64, default arch [K,16,16,32]/[2,32,32,32,32],
#         SOAP (lr 3e-3, betas 0.95,0.95, wd 0.01, precond_freq 100),
#         soap-epochs 25000 ceiling with early-stop patience 150, seed 1234567.
# Size  : --skip-validation-plots on all training runs (the 81 per-case PNGs are
#         ~48 MB/run; summary CSV kept). Regenerate plots for the winner only via
#         --validate-only WITHOUT the skip flag.
# Eval  : each run auto-validates on the 81 four-zone COMSOL cases; the
#         eval_operator_across_zonations lines afterwards add the zonation
#         1-6 OOD sweep per model (inference only, fast).
# Single seed for the grid; replicate the winner with 2 more seeds after,
# exactly as the X- and G-series did.
# Runtime : ~50 min/run -> ~5 h training + fast evals.
#
# --- training: mix grid (GRF share 0 -> 100%) ---
