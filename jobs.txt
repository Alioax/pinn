# PINO_2 (pure GRF) grid  -  paper heterogeneous section, GRF-only variant.
# Prior batch (X3/X4/X6 SOAP seed replicates) is DONE; those result dirs already exist.
#
# Design: train the operator on smooth GRF velocity fields ONLY (no piecewise),
#         test on the existing 81 four-zone COMSOL cases (no new COMSOL needed).
# Grid  : correlation length ell in {0.05, 0.10, 0.20}  x  sensor count K in {50, 100, 150, 200}  = 12 runs.
# Fixed : N=500 GRF fields, float64, default arch [K,16,16,32]/[2,32,32,32,32],
#         SOAP (lr 3e-3, betas 0.95,0.95, wd 0.01, precond_freq 100),
#         soap-epochs 25000 with early-stop patience 150 (reproduces the X3 recipe;
#         X3 early-stopped near 5.7k epochs, so 25k is a ceiling not a target).
# Rationale: ell is the smoothness-vs-zone-transfer axis (0.20 barely varies across a zone
#            -> the stale 8-13% baseline; 0.05 is the roughest safe at K=50, spacing 0.02).
#            K sweep answers the outline's mandated "impact of number of sensors".
# Runtime : ~50 min/run on the RTX 3090  ->  ~10 h wall for all 12.
#
# --- ell = 0.05 ---
