## Validation outcome (PINN reference vs real COMSOL)
Single-instance PINN accuracy ~1%; every reference with a COMSOL counterpart matched:
0.01/0.01/0.01/0.01 -> **0.68%**, 2-zone 0.05/0.01 @0.5 -> **0.91%**,
0.05/0.01/0.05/0.01 -> **1.42%**. The p90 proxy predicted these. **Method validated.**
Caveat: 7/10 generated refs were off the COMSOL grid (velocities 0.02/0.04; 3-zone
at equal thirds) so couldn't be checked - target the grid next time.
