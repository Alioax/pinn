# Homogeneous medium — Pe parameterization (Report 3)

Final scripts for the re-established 1D advection–dispersion study (regular 50³ collocation, L-BFGS only, **log Pe** as the parameter).

| Subfolder | Model |
|-----------|--------|
| `baseline_pinn/` | Single-regime PINN |
| `parametric_pinn/` | Parametric PINN over Pe |
| `pino/` | DeepONet-style PINO |

Each folder is self-contained (`results/` beside the script).
