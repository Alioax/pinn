# review_ready

Minimal, self-contained scripts prepared for supervisor/team review.

| Project | Description |
|---------|-------------|
| **pinn_baseline** | PINN for 1D advection–dispersion (single Péclet number). |
| **parametric_pinn** | Parametric PINN (multiple Pe). |
| **neural_operator_deeponet** | Neural operator / DeepONet baseline. |

Each folder contains one or more scripts; parameters and analytical formulae are kept in-file. Outputs go in each project’s folder (or `results/` where used).
